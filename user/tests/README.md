# user/tests

This directory contains all test code, test data, and test outputs for the user-scoped integration work.

## Layout

- data/: input archives and fixtures for smoke tests.
- logs/: test run logs.
- run-smoke.sh: basic validation script.

## Scope

- Keep all new tests for this integration under user/tests.
- Do not write test artifacts outside user/tests and user/logs.
